Lato beta 2 keeps interactive configuration and everyday commands inside the full-screen TUI.

- Fix `/model` leaving the TUI. Provider/model pickers support filtering, exact-name matching, arrow-key selection and Esc cancellation; successful switches preserve the current session and conversation context.
- Keep first-run setup, folder trust, API-key input, browser/device OAuth login, session switching and offline diagnostics inside the TUI. API-key inputs are masked.
- Fix the input cursor appearing on the border. Cursor positioning now follows Chinese, emoji, combining characters, editing in the middle and horizontally scrolling long input.
- Reserve `/` for slash commands; use Ctrl-F or `/search` to open conversation search. Add `/new`, `/sessions` and `/doctor` command entry points.
- Include the bilingual TUI, Codex subscription provider transports/authentication and tool-chain repairs developed since beta 1.

Download the archive for your platform and verify it against `SHA256SUMS`. Existing CLI commands remain available for scripts. Live provider login/completion was not exercised for this release; regression tests use local fixtures.

Validation: 430 local workspace tests, strict Clippy, formatting and debug/installed-binary PTY smoke tests pass on macOS. GitHub full-workspace CI currently fails on Linux and Windows; the same jobs also failed on the preceding remote commit. The specific causes have not yet been verified, so this prerelease does not claim a clean cross-platform test run. See the [CI run](https://github.com/hyzwhu/lato/actions/runs/33722852718).
