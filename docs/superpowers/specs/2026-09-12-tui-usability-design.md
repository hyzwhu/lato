# Lato TUI 易用性升级（已实施）

## 现状与目标

当前 TUI 有 18 个静态 slash 命令，按名称前缀筛选；另有独立命令面板。输入显示为单行，宽屏固定分配会话、聊天、工具三栏。后端已有插件 skill 目录及用户调用语义，但 TUI 缺少文件引用和 skill 选择入口。

目标：用户无需记忆命令即可发现功能、引用项目文件、选择可用 skill，并能清楚区分输入、执行状态和工具结果。

## 方案比较

1. 推荐：聊天优先布局与统一输入选择器。覆盖最常见操作，复用当前 ratatui 和后端。
2. 保守：保留三栏，仅补全文件和 skill。变更小，但输入空间和信息密度问题仍存在。
3. 全面重做终端工作台。覆盖更多面板与定制能力，范围明显超过本轮需求。

## 交互设计

- 默认突出聊天区域，会话及工具面板按需展开；窄屏保留输入、当前任务状态与必要快捷键。
- `/` 打开分组选择器，展示命令名称、说明、参数提示；名称优先匹配，同时支持描述检索。内置命令和用户可调用 skill 共用入口；别名可检索，但默认不重复占行。
- Ctrl+K 保持命令面板入口，与 slash 共用命令注册及执行定义。
- `@` 在输入光标位置搜索项目文件。候选包含相对路径，遵守 gitignore，排除构建目录；支持空格及中文路径。Tab 或 Enter 选择时仅插入引用，不发送消息；Esc 关闭候选并保留草稿。
- 文件候选通过有上限的后台扫描构建，不在每个按键事件中递归扫描。目录切换使缓存失效。选中文件以可编辑的 @ 引用标记保留在草稿，发送时解析为带来源的 JSON 上下文，验证规范化路径位于工作区内并读取文本；文件消失、二进制、超限等情况给出可操作错误且保留草稿。单文件上限 64 KiB、总引用上限 256 KiB，不静默截断。
- `/skills` 浏览后端当前有效 skill，展示名称、描述、来源、参数提示；`/skill <qualified-name> [args]` 为无歧义调用入口。用户可调用 skill 可作为动态 slash 候选，名称冲突时使用限定名称；真正执行沿用用户调用语义和现有权限约束。
- skill 空列表说明发现来源及检查方法；加载失败显示错误和重试入口。面板与运行时使用同一代目录快照。
- 输入框根据内容增长，最多占 8 行，超过后内部滚动；Enter 发送，Alt+Enter 换行，支持可识别的 Shift+Enter。多行粘贴不触发发送。上下键先服务候选，再服务多行光标，在首末行边界浏览输入历史并保存未发送草稿。
- 底部根据当前操作展示快捷键、模型和执行状态；补全关闭、任务取消与退出使用明确的优先级，避免 Esc 关闭候选时取消任务。
- 沿用中英文切换，统一选中态、边框、弱化文本与错误样式。无独立 DESIGN.md，推荐本轮沿用当前终端配色，仅在此文档约定布局和交互。

## 实现边界

将候选查询、选择与光标范围替换从渲染中分离；commands 作为内置命令唯一来源，文件索引作为后台数据源，skill 列表从现有后端目录获取。输入模型提供多行坐标与安全的 Unicode 范围编辑。后端负责引用读取与 skill 调用，渲染只消费状态。

保留已有会话、审批、模型切换、工具面板能力。仓库已有 Cargo.toml 和 lato-workflow 未提交工作，实施时避免覆盖这些内容。

## 验收与部署

- 单元测试覆盖候选导航、Esc 和 Enter 优先级、光标中间替换、Unicode、多行及历史草稿恢复。
- 集成测试验证文件实际进入请求、读取失败保留草稿、skill 用户调用及不可调用过滤。
- ratatui TestBackend 覆盖 60/90/120 列及小高度，保证候选与输入可见。
- 扩展现有 PTY smoke，通过真实键盘序列验证 slash、文件、skill 和多行操作；使用本地模型 fixture。
- 运行相关测试、格式检查及必要构建后，执行仓库要求的 `cargo install --path .`，验证安装的 `lato`。

## 实施补充

命令面板切换时暂存草稿并支持恢复；文件内容也可作为独立附件跟随带位置参数的 skill。对话自动跟随最新消息，PgUp/PgDn 浏览历史，浏览时保持阅读位置。索引最多返回 10,000 个文件，文件及 skill 候选最多 100 项；/files、/skills 可刷新。文件索引依赖 rg 或 git，缺失时显示错误。引用按输入标记解析，@word 是显式引用而 email 不受影响。

## 动态生成与底部上下文（追加实施）

在已有 reasoning 事件上提供过程卡片：收到模型公开返回的 reasoning 增量后实时展开，按实际事件顺序插入对话；开始回答或执行工具时结束该思考段并收起，F2 可展开/收起思考记录。进行中的卡片显示动态指示、耗时和最新若干行。未返回 reasoning 时仅标注等待、工具执行或输出回答，不生成虚构思考文本。

底部常驻上下文信息，不被生成状态覆盖：输入 token 估算 / 已知窗口 / 使用率与用量条、模型、当前状态和耗时；窄屏采用精简数字。未知窗口显示未知，不当作零；生成期间标明最近一次采样估算。审批、压缩和工具执行显示各自状态，运行指示基于 tick 刷新。测试覆盖 reasoning→工具→reasoning→回答顺序、无 reasoning、F2、取消和不同宽度的底部信息。
