# Lato Phase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Scope lock:** This plan is **phase 0 only**. Do not implement real HTTP dialects, OAuth, OS sandbox wrappers, MCP, plugins, skills, compact, `spawn_subagent`, or `web_*`. Those are later plans.
>
> **Done means:** every non-LIVE case in `docs/superpowers/specs/2026-08-31-lato-acceptance.md` section **A** (and G1–G4 as they apply) is a named `cargo test` that PASSes. Do not claim phase 0 complete by vibe.

**Goal:** Ship a Rust headless coding-agent kernel: ACP host + one-session turn loop + fake model + five coding tools + env/api-key store, invocable as `lato -p` without a TTY.

**Architecture:** Root crate `lato` is the CLI. Library crates under `crates/` hold protocol, credentials, workspace paths, tools, and the session actor. CLI talks to the host only through an in-process ACP channel (`tokio::mpsc` JSON-RPC), never `run_turn` directly. Sampling uses a `ModelStream` trait; phase 0 ships `FakeModelStream` only.

**Tech Stack:** Rust edition 2024, Cargo workspace, Tokio, serde/serde_json, thiserror, regex, dirs, tempfile (dev). No `reqwest` in phase 0.

## Global Constraints

- Product id `lato`. CLI binary `lato`. ACP extensions `lato/`. Tool ids `Lato:*`. State dir `$LATO_HOME` (default Unix `~/.lato/`, Windows `%USERPROFILE%\.lato\`).
- Language: Rust, edition 2024, single language, code only in the `lato` git repo.
- `lato-ai` must not depend on `lato-agent`. `lato-agent` uses ai only via `get_auth` and `ModelStream`.
- `lato -p` implies `approval_mode=always` and process-local trusted cwd; does not persist folder trust; does not block on TTY. Interactive default remains `ask`.
- Phase 0–1: no compact; exceeding `CONTEXT_HARD_LIMIT_BYTES` fails the turn; no silent truncate.
- File lock key = canonical absolute path (Windows: strip `\\?\`, unify separators, case-fold). Same function for folder-trust keys.
- ToolRouter in phase 0: `read_file`, `list_dir`, `grep`, `search_replace`, `run_terminal_command`, `todo_write` only.
- Sandbox profile may be `off`. Default Windows shell: `pwsh` if it exists else `powershell.exe`. Unix: `$SHELL` or `bash`.
- Tests set `LATO_HOME` to a temp dir. No live network. Map tests to acceptance IDs in test names (`a0_1_headless_always`, etc.).
- Do not advertise or implement `session/load`.

use std::path::{Component, Path, PathBuf};

pub fn lock_key(path: impl AsRef<Path>) -> PathBuf {
    #[cfg(windows)]
    {
        return PathBuf::from(windows_lock_key_for_test(path.as_ref().to_string_lossy().as_ref()));
    }
    #[cfg(not(windows))]
    {
        unix_lock_key(path.as_ref())
    }
}

pub fn windows_lock_key_for_test(raw: &str) -> String {
    let mut s = raw.replace('/', "\\");
    if let Some(rest) = s.strip_prefix(r"\\?\") {
        s = rest.to_string();
    }
    s.to_lowercase()
}

#[cfg(not(windows))]
fn unix_lock_key(path: &Path) -> PathBuf {
    if let Ok(c) = std::fs::canonicalize(path) {
        return c;
    }
    let abs = if path.is_absolute() {
        path.to_path_buf()
    } else {
        std::env::current_dir().unwrap_or_else(|_| PathBuf::from(".")).join(path)
    };
    let mut out = PathBuf::new();
    for c in abs.components() {
        match c {
            Component::CurDir => {}
            Component::ParentDir => {
                out.pop();
            }
            other => out.push(other.as_os_str()),
        }
    }
    out
}
```

use std::ffi::OsString;
pub fn default_shell() -> OsString {
    #[cfg(windows)]
    {
        if which("pwsh") { return OsString::from("pwsh"); }
        return OsString::from("powershell.exe");
    }
    #[cfg(not(windows))]
    {
        std::env::var_os("SHELL").unwrap_or_else(|| OsString::from("bash"))
    }
}
#[cfg(windows)]
fn which(name: &str) -> bool {
    std::env::var_os("PATH").is_some_and(|p| {
        std::env::split_paths(&p).any(|dir| dir.join(name).is_file() || dir.join(format!("{name}.exe")).is_file())
    })
}
```
