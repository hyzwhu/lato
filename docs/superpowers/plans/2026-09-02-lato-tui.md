# Lato Native Bilingual TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Lato's readline interactive mode with a native Ratatui interface that streams real sessions and tool activity in Chinese and English while preserving all headless CLI contracts.

**Architecture:** A new `src/tui/` module runs a unidirectional event loop: terminal and ACP events enter a reducer, state renders through pure widgets, and asynchronous effects operate on `InteractiveAcpClient`. CLI bootstrap remains in `src/cli.rs`; the existing client receives typed update normalization and cancellation support.

**Tech Stack:** Rust 2024, Ratatui, Crossterm, Tokio, Unicode Width, Unicode Segmentation, Serde, Clap, existing Lato ACP runtime.

## Global Constraints

- `lato` and `lato resume <session-id>` launch the TUI only when stdin and stdout are TTYs.
- `lato -p`, `sessions`, `login`, `doctor`, and `acp` retain current output and exit-code contracts.
- Supported locales are exactly `zh-CN` and `en`; precedence is CLI, persisted config, system locale, then English.
- Stable UI text is translated; user/model/tool payloads are never translated.
- Terminal state must be restored after normal exit, error, cancellation, and panic.
- Narrow layouts degrade from three columns to drawers; undersized terminals show a resize message.
- Run relevant tests before the required final `cargo install --path .` deployment.

```rust
#[derive(Clone, Copy, Debug, Default, Eq, PartialEq, clap::ValueEnum, serde::Serialize, serde::Deserialize)]
pub enum Language {
    #[value(name = "zh-CN")]
    ZhCn,
    #[default]
    #[value(name = "en")]
    En,
}

impl Language {
    pub fn resolve(cli: Option<Self>, persisted: Option<Self>, system: Option<&str>) -> Self {
        cli.or(persisted).unwrap_or_else(|| {
            system.filter(|value| value.to_ascii_lowercase().starts_with("zh"))
                .map(|_| Self::ZhCn).unwrap_or(Self::En)
        })
    }
}
```

Extend `CliSettings` with `#[serde(default)] language: Option<Language>` so existing config files remain valid and save language changes through the existing atomic writer.

pub async fn cancel(&mut self) -> Result<(), String> {
    let id = self.take_id();
    let response = self.host.handle(req(

- [ ] **Step 4: Implement terminal guard and event loop**

```rust
pub struct TerminalGuard { active: bool }

impl Drop for TerminalGuard {
    fn drop(&mut self) {
        if self.active {
            let _ = crossterm::terminal::disable_raw_mode();
            let _ = crossterm::execute!(std::io::stdout(),
                crossterm::terminal::LeaveAlternateScreen,
                crossterm::cursor::Show
            );
        }
    }
}
```

Drive redraws from Crossterm's `EventStream`, backend events, and a 100 ms tick. Map keys contextually so text entry never triggers panel shortcuts. Bootstrap the real client through reusable CLI helpers, and route `InteractiveNew`/`Resume` to `run_tui` while retaining the non-TTY guard.
